## 四维分解

### 1. 数据源：复权、停牌、交易日历

| 项 | 本地 / QC | 聚宽 | 量化 |
| --- | --- | --- | ---: |
| 价格 | 同一静态 qfq CSV | 原生 `510300.XSHG` + `use_real_price`（动态前复权） | 因子恒为 1，无法在本 ETF 上拆开；交叉日平移 1 天的代理是 **+0.38 pp 年化** |
| 停牌 | `volume=0` 跳过成交，bar 留在均线窗口 | `skip_paused=False`，同样跳过 `volume=0` | **0.00 pp**（0 根停牌） |
| 日历 / 截止日 | 本地到 2026-08-25；QC 自定义数据到 2026-05-29 | 回测到 2026-06-26 | 截到 QC 末日 **+0.55 pp**；截到聚宽末日 **+0.46 pp**（相对全样本）。这是三平台头条总收益对不上的第一原因。 |

### 2. 成交假设：开盘 / 收盘 / 次日开盘

规格是 **T 收盘后才知道 \(w_t\)，最早 T+1 开盘**。QC：`OnData` 存昨日权重、打今日 Open。聚宽：`run_daily(..., 09:31)`，`attribute_history` 不含今日。

| 成交 | Δ年化 | 是否可交易 |
| --- | ---: | --- |
| T+1 开盘（规格） | 0 | 是 |
| T+1 收盘 | **−0.31 pp** | 是，但不是本规格 |
| T 收盘打 T 收盘 | +0.05 pp | 前视 |
| T 收盘打 T 开盘（早 1 天） | **+0.38 pp**，夏普 0.258→0.318 | 前视，最危险的「变好」 |

### 3. 手续费：平台默认 vs 覆盖后

| 费率 | Δ年化 | 费用（元） |
| --- | ---: | ---: |
| 本地 / 三平台覆盖后：ETF 万 1、无印花税、5 bps | 0 | 3,607 |
| 聚宽**股票**默认（万 3 + 印花税千 1） | **−0.30 pp** | 26,350 |
| QC **IB** 默认近似 | **−0.48 pp** | 40,251 |
| 零成本 | +0.26 pp | 0 |

未覆盖默认费率，对年化的伤害 **大于** 对齐截止日后剩下的引擎残差。本回测两边都已覆盖：QC `AshareEtfFeeModel`，聚宽 `set_order_cost(..., type='fund')`。

### 4. 绩效计算：年化与夏普口径

同一条本地权益曲线，只换公式：

| 口径 | 数值 | Δ vs 本报告默认 |
| --- | ---: | --- |
| CAGR \((1+R)^{252/n}-1\) | **1.93%** | 默认 |
| CAGR \((1+R)^{365/\text{日历天}}-1\) | 1.85% | **−0.07 pp** |
| 算术年化 mean×252 | 2.31% | **+0.38 pp** |
| 夏普 rf=0，ddof=0，√252 | **0.258** | 默认 |
| 夏普 rf=2% | **0.035** | 策略年化低于 2% 时夏普≈0 |
| 夏普 rf=4%（聚宽默认近似） | **−0.189** | 与聚宽头条 −0.153 同号 |
| 夏普 rf=0，√365 | 0.311 | 把交易日收益当年历日 |

聚宽头条夏普 **−0.153** 不是策略变差：年化 2.60%、波动 9.1%，\((2.60\%-4\%)/9.1\% \approx -0.15\)。改 rf=0 约为 **0.29**，与本地对齐截止日后的 0.31 同量级。

## 哪个最接近「真实可交易结果」？（约 300 字）

本地引擎最接近场内 ETF 可交易结果。权重只能在 T 收盘后算出，最早 T+1 开盘成交；若用当日收盘打当日开盘，年化虚高 0.38 个百分点、夏普从 0.258 抬到 0.318，那是前视不是 alpha。费率按 ETF 万 1、无印花税、整手 100；套用聚宽股票默认或 QC 的 IB 费率，年化分别少 0.30 和 0.48 个百分点——比对齐截止日后剩下的引擎残差更大。本样本无停牌、复权因子为 1，日历几乎不扰动交叉日，但不能推广到个股；真正扰动三平台头条的是**样本截止日**（截到 5 月底年化高 0.55 个百分点）。绩效用交易日 CAGR、rf=0 的 252 夏普；改 rf=4% 夏普会到 −0.19，聚宽头条 −0.15 是口径不是亏损。聚宽更贴近 A 股日历，必须覆盖基金费率和 09:31。QC 能跑同一公式，paper 却不是上交所竞价。三者里只有本地同时约束了能买到的价、付得出的费、和口径一致的绩效。
